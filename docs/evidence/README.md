# Historical verification evidence

The files in this directory are immutable records of commands, paths,
artifacts, and checksums captured before the current project namespace was
adopted. Their identifiers are preserved verbatim so that hashes and recorded
observations remain auditable.

They are historical evidence, not current installation or usage guidance. Use
the documentation in the parent directory for the current Farrow commands,
paths, configuration, and release layout. New verification runs should be
recorded with the current namespace rather than editing an existing record.
